# Sabor Express

Sistema de gerenciamento de restaurantes desenvolvido em Python.

## Funcionalidades

- Cadastro de restaurantes
- Listagem de restaurantes
- Alteração de status
- Integração com API ViaCEP
- Busca automática de cidade e estado através do CEP

## Tecnologias utilizadas

- Python
- Requests
- Pytest
- Git/GitHub

## API utilizada

- ViaCEP

## Como executar o projeto

### Clone o repositório

```bash
git clone URL_DO_REPOSITORIO
```

### Entre na pasta do projeto

```bash
cd bootcamp
```

### Ative a venv

```bash
.venv\Scripts\activate
```

### Instale as dependências

```bash
pip install requests pytest
```

### Execute o projeto

```bash
python app.py
```

## Testes

Para rodar os testes:

```bash
pytest
```
